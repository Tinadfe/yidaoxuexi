# 医道学堂 · 使用说明

中医 × 道家 · 边学边练的个人学习平台（单用户自用版）。
架构与灵犀笔记同款：FastAPI + SQLAlchemy + SQLite + PWA。

## 一、启动（本地 / 服务器）

```bash
cd yidao
pip install -r requirements.txt          # 首次
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8700
```

- 手机浏览器打开 `http://服务器IP:8700`
- **添加到主屏幕**（iPhone：Safari 分享 → 添加到主屏幕）即得全屏 App 体验
- 首次启动会自动建库并导入 141 张初始卡片（道德经 81 章 + 药材 40 味 + 穴位 20 个）

## 二、每天怎么用（约 30 分钟）

| 时段 | 动作 | 用时 |
|---|---|---|
| 白天碎片 | 「学习」页：点卡翻面 → 记住了 ✓ / 再看看 | 5 分钟 |
| 晨起/晚间 | 「功法」页：选八段锦/站桩/静坐 + 时长 → 完成打卡 | 15–30 分钟 |
| 随时 | 「我的」页看进度（分类进度条 + 连续打卡天数） | 1 分钟 |

- 每日自动推送：新卡 2 张（医 1 + 道 1）+ 到期复习卡（最多 5 张）
- 「记住了」按艾宾浩斯间隔重现：1 → 2 → 4 → 7 → 15 → 30 天
- 「再看看」次日重来，学过 6 轮标记为「已掌握」

## 三、道德经诵读音频（已全部配好）

81 章已用 AI 神经网络男声（微软云希）配好朗读，语速放慢 15%，接近诵经节奏，
文件在 `yidao/data/audio/tao_001.mp3` ~ `tao_081.mp3`。卡片翻面后点 🔊 即可播放。

**想换成自己的真人录音？** 直接替换同名文件即可，零代码改动：

1. iPhone「语音备忘录」录道德经某一章 → 分享导出（m4a 转成 mp3）
2. 上传到服务器 `yidao/data/audio/` 目录
3. 命名规则：`tao_001.mp3`（第一章）… `tao_081.mp3`（第八十一章）
4. 覆盖同名文件后，卡片播放的就是你的声音

> 自己读的，记得最牢。录完 81 章就是一套私人定制的诵读库。

**重新生成 AI 音频**（可选，如果想换声音/语速）：

```bash
pip install edge-tts
# 示例：女声晓晓、语速 -10%
edge-tts --text "第一章原文" --voice zh-CN-XiaoxiaoNeural --rate=-10% --write-media data/audio/tao_001.mp3
```

## 四、数据与备份

- 全部数据就是 **一个文件**：`data/yidao.db`
- 备份：改动/升级前 `cp data/yidao.db data/yidao.backup.db` 即可
- 想重新开始：停服务 → 删除 `data/yidao.db` → 重启（自动重新导入全部卡片）

## 五、部署（Bonto 免费服务器）

与灵犀笔记相同的流程：上传 `yidao` 目录 → 安装依赖 → 启动 uvicorn（建议用 systemd 或 screen 常驻）。
建议端口改掉 8700 或加防火墙限制，因为 MVP 是自用版、没有登录鉴权。
